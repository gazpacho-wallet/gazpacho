# Security

**Gazpacho is not ready for real funds.** It is at the design and early-code stage, and the first releases are for signet only.

## Reporting a problem

Please report anything that could let someone take or freeze another person's funds privately, using GitHub's "Report a vulnerability" button on this repository's Security tab. Do not open a public issue for it.

For problems in the imported SuperScalar files under `core/superscalar/`, report to the SuperScalar repository as well, since the fix belongs there.

## What to expect

This is a small project. You will get an acknowledgement, a discussion of the problem, and credit in the fix if you want it. There is no bounty.

## Known limits

The documents under `docs/` state openly what is unfinished and what has not been reviewed. See `docs/KNOWLEDGE-BASE.md`, section "How sure we are".
